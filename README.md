# tubeproof

Research real practitioner experience on YouTube. Given a topic, tubeproof finds popular videos and course playlists (any language, date-filtered), reads transcripts, descriptions, linked pages and comments, strips only the paid/sales parts, cross-checks claims across independent sources, comments and official docs, and writes a confidence-scored report with timestamped citations.

- **Independence by source, not by channel:** creators repeating the platform's docs count as one vote, copied scripts and channels of one company are merged.
- **Code computes the scores;** the model only labels. Every quote is matched against the transcript; links are generated by code.
- **Practitioner vs docs:** when they disagree the report explains why and proposes a cheap test on your own data.

Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · research principles: [docs/PRINCIPLES.md](docs/PRINCIPLES.md) · single sources of truth: [docs/SSOT.md](docs/SSOT.md).

## Install

```bash
python3 -m venv .venv && .venv/bin/pip install -e '.[whisper-mlx]'   # Apple silicon; use '.[whisper]' elsewhere
```

Needs Node.js 22+ (yt-dlp's JS challenge solver), ffmpeg, and the [Claude Code](https://claude.com/claude-code) CLI logged in (the default LLM backend runs `claude -p`). No API key is needed for harvesting.

## Use

```bash
mkdir -p research/2026-11-my-topic && $EDITOR research/2026-11-my-topic/pack.yaml   # see the example research
tubeproof harvest 2026-11-my-topic --plan     # select videos, writes plan.json
tubeproof process 2026-11-my-topic            # harvest, transcribe, analyse, cluster, verify, write REPORT.md
tubeproof report 2026-11-my-topic --render    # re-render links and appendix without a model call
```

Add `research/<id>/private/context.yaml` (`question`, `context`, `hypotheses`) to also get a report about your own situation in `private/REPORT.md`; that folder is never committed. The report language is set per pack (`report_lang`, e.g. `tr`); the tool, code, logs and docs are English.

As an MCP server (Claude Code): add to `.mcp.json`

```json
{"mcpServers": {"tubeproof": {"command": "/path/to/tubeproof/.venv/bin/tubeproof-mcp",
  "env": {"TUBEPROOF_DATA_DIR": "/path/to/tubeproof/tubeproof-data", "TUBEPROOF_RESEARCH_DIR": "/path/to/tubeproof/research"}}}}
```

## Research layout

A research id is its folder path under `research/`. Researches on one theme can be grouped in a parent folder: `research/youtube-video-strategies/2026-10-youtube-retention/` has the id `youtube-video-strategies/2026-10-youtube-retention` (`tubeproof process youtube-video-strategies/2026-10-youtube-retention`).

| Path in `research/<id>/` | Contents | Committed? |
|---|---|---|
| `pack.yaml` | Topic, queries, official domains, platform change dates, report language | yes |
| `plan.json` | The selected videos and why | yes |
| `REPORT.md`, `report_body.md` | Shareable findings: short quotes with timestamped links, dated (`report_body.md` is the model text the report is rendered from) | yes |
| `guide/` | Optional how-to guides built on the report (checklists, recipes), generic, citing report clusters | yes |
| `data/` | Run data: transcripts, comments, extractions | never |
| `private/` | Your context, hypotheses and your report | never |

## Data and privacy

Harvested data stays local (`tubeproof-data/`, 30-day cache), is never committed or redistributed, and comment authors are stored only as hashes. Contributors: enable the push privacy check once per clone with `git config core.hooksPath .githooks`; it scans every pushed file version for private terms (your own list in `~/.config/tubeproof/private-terms.txt`), secrets, transcripts and forbidden paths.
